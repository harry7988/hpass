pwhide 使用流程与编码验证

它解决什么问题

让 AI 执行带密码的命令，而密码不进入对话、日志与历史。

密码以 AES-256-GCM + RSA-3072 信封加密存于本地；主口令可存系统钥匙串实现零交互。

五分钟上手

四条命令完成从初始化到交给 AI。

AI 侧配置一次即可：把可见性契约写进 AGENTS.md，或安装内置 Skill（skills/pwhide/install.sh）。

人工核验通道

确认存的密码是对的——AI 无法触达。

pwhide verify 条目 与 exec --verify 只在真实交互终端可用，强制手输主口令；被 AI 调用直接拒绝。

Windows 编码：为什么一直乱码，现在怎么解决

cmd 的 OEM 代码页（GBK）+ PowerShell 的 [Console]::OutputEncoding + 管道重定向换解码器——同一份输出，消费方不同结果不同。0.7+ 按句柄类型自动适配；仍不对时 doctor --output-encoding 一条命令全局兜底。

字节级验证报告

真实二进制产出 × Windows 各解码器精确还原，验证脚本随仓库提供（scripts/encoding-visual-proof.py）。
